### Dynamic Row Structure (generated by `bearing-table.js`)

Each row in `<tbody>` has this innerHTML pattern (set in `updateRow()`):

```html
<td style="color:{entityColor};">{shipName}</td>
<td>{bearing in degrees}</td>
<td>{distance in Ks}</td>
<td>{heading in degrees}</td>
```

Row `id` is the numeric row index (e.g., `<tr id="0">`, `<tr id="1">`).

## Required Behaviors

| # | Behavior | Source |
|---|----------|--------|
| 1 | Table auto-populates rows for nearest entities (type 1=player, 4=enemy, 5=station, 14=creature), excluding own vessel and already-listed entities | `bearing-table.js:15-41` |
| 2 | Rows are added until table height fills `window.innerHeight` | `bearing-table.js:89-108` |
| 3 | If table exceeds viewport height (e.g. screen rotation), last row is deleted | `bearing-table.js:109-114` |
| 4 | When table is full, nearest unknown vessel replaces furthest known vessel if closer | `bearing-table.js:119-133` |
| 5 | Destroyed entities have their rows removed from table | `bearing-table.js:77-85` |
| 6 | Each row displays: ship name (color-coded by `getColor()`), bearing (degrees), distance (Ks), heading (degrees) | `bearing-table.js:152-184` |
| 7 | Red alert toggles `body` class to `red-alert` via `redalert.js` on `iface.on('playerUpdate')` | `redalert.js:4-16` |
| 8 | Connection lost overlay managed by `connectionlost.js` — shows status in `#connected` div | `connectionlost.js:6-113` |
| 9 | Game over screen displays title, reason, and stats in `#connected` overlay | `connectionlost.js:57-79` |

## Update Cadence

| Timer | Interval | What It Updates | Source |
|-------|----------|-----------------|--------|
| `window.setInterval(updateTable, 100)` | 100ms | Iterates rows: on tick either adds/removes/swaps a row or updates one row's BRG/DST/HDG. Cycles through all rows before checking row count again (`rowID` decrements from `tbody.rows.length` to `-1`). | `bearing-table.js:188` |

## Known Legacy Bugs

| # | Bug | File:Line | Details |
|---|-----|-----------|---------|
| 1 | **Row id collision with numeric strings** | `bearing-table.js:147` | `row.id = newRowID` sets `<tr id="0">`, `<tr id="1">` etc. Numeric-only IDs are technically valid in HTML5 but can cause issues with `getElementById` in older browsers and CSS selectors like `#0`. |
| 2 | **`getColor()` called but never defined in bearing-table.js** | `bearing-table.js:174` | `getColor(model.entities[entityID])` is called but not defined in this file. Must be defined in `prettyprint.js` or `worldmodel.js`. If missing, throws a ReferenceError and row innerHTML is not set. |
| 3 | **`posToBrgDst()` and `radianToDegrees()` / `distanceToKs()` assumed global** | `bearing-table.js:25,179-181` | These functions are expected from `angles.js`/`prettyprint.js`. Not imported — relies on global scope. |
